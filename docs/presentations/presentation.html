College Research Project

LinguaAI

Preserving Voices
Before They Fade

Harnessing AI to document and protect critically endangered native languages.

The Problem

According to UNESCO, a language dies every 14 days.

  • Out of 7,000+ spoken languages, over 3,000 are endangered.
  • When a language is lost, indigenous knowledge, history, and cultural identity are erased.
  • Traditional documentation by linguists is slow and resource-intensive.

Our Solution: LinguaAI

An accessible, web-based platform that democratizes language preservation by combining Community Effort with Artificial Intelligence.

  • 🌍 Global Database: Public educational database of endangered statuses.
  • 🎙️ Speech AI: Live speech recognition for low-resource transcription.
  • 💾 Safe Archiving: A centralized MySQL backend structure to safely store recorded culture.

Methodology & Process

  1. Literature Review: Studied UNESCO Atlas & linguistic papers.
  2. Technology Selection: HTML/PHP for optimal accessibility (rural connectivity) and Web Speech API for transcription.
  3. Data Gathering: Categorized 25 critically endangered languages for our seed archive.
  4. Implementation: Built dual User/Admin systems with authenticated sessions.

Technology Stack

Frontend

  • Vanilla HTML5 & CSS3
  • JavaScript (jQuery)
  • Web Speech API (AI Model)

Backend

  • PHP (Session Management)
  • MySQL (Relational Database)
  • Native Authentication

Key Features (User)

  • Secure User Registration and Session Login.
  • Interactive Endangered Languages Atlas.
  • Live Web Speech Transcriber to convert mic input to text.
  • Save, fetch, and download Transcriptions.
  • Contact forms to submit field-recorder findings.

Key Features (Admin)

  • Secluded Admin Portal login workflow.
  • Complete view of the centralized Transcription database.
  • CSV Data Exports for Researchers / Academics.
  • Review global Contact inquiries directly from platform.

Conclusion & Future Scope

LinguaAI demonstrates that modern technology doesn't have to erase indigenous cultures — it can help save them.

  • Future: Integration of Whisper (OpenAI) backend models.
  • Future: Native offline Mobile App for deeper field research.
